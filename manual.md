# Mamma Movie – Manual

## 1. Anwendung starten

### Online
Die Anwendung kann direkt im Browser verwendet werden:

https://mamma-movie.onrender.com

### Lokal
Das Projekt kann auch lokal über Java und Maven gestartet werden.

## 2. Filme suchen und empfehlen

Auf der Startseite können verschiedene Filter verwendet werden, um passende Filme zu finden.

Mögliche Filter sind:
- Genre
- maximale Laufzeit
- Stimmung

Anschließend kann eine Filmempfehlung angefordert werden.

## 3. Filmempfehlung

Mit der Funktion zur Filmempfehlung wird ein passender Film angezeigt.

Mit **„Noch einen Film“** kann eine weitere Empfehlung angefordert werden.

Mit **„Überrasch mich“** kann eine zufällige Empfehlung ausgewählt werden.

## 4. Gesehene Filme

Filme können als **„Schon gesehen“** markiert werden.

Bereits gesehene Filme werden bei weiteren Empfehlungen berücksichtigt und nicht erneut empfohlen.

## 5. Favoriten

Filme können zu den **Favoriten** hinzugefügt werden.

Über **„Meine Favoriten“** können die gespeicherten Lieblingsfilme angezeigt werden.

## 6. Streaming-Informationen

Für verfügbare Filme können Streaming-Informationen für Österreich angezeigt werden.

Die Filmdaten und verfügbaren Anbieter werden über die TMDB-Schnittstelle bereitgestellt.

## 7. Filter zurücksetzen

Mit der Funktion zum Zurücksetzen können die gesetzten Filter wieder entfernt und die Standardsuche hergestellt werden.

## 8. Ziel der Anwendung

Mamma Movie unterstützt Benutzer dabei, passende Filme anhand ihrer persönlichen Interessen und Filtereinstellungen zu finden.
